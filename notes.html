🏠 HomeCore V2 | Turning a Raspberry Pi Into a Home Brain

HomeCore started as a simple idea: make a Raspberry Pi useful as a personal home system instead of leaving it as just another device on the network. V2 is a much bigger continuation of that idea, bringing the dashboard, system information, network visibility, storage and device status together into one place.

The new direction also includes an iPhone to laptop photo bridge, so moving photos around the home network can become part of the same system. The dashboard is being built to expose useful information such as CPU temperature, RAM, disk usage, uptime, Pi and OS information, network speed, latency, interfaces, IP details, gateway/internet status and storage.

I'm building HomeCore V2 as a self hosted system around a Raspberry Pi, with a FastAPI backend and React frontend, while keeping the system practical and lightweight. The project also ties into my Linux and networking work through APIs and Tailscale access.

This is still an ongoing project. The goal is no longer just a dashboard that looks good. It's becoming a small personal infrastructure layer that I can actually use around the house.
