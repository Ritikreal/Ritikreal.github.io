Desk Buddy · Privacy Policy

Effective: 25 September 2026

This Privacy Policy explains how Desk Buddy handles information when its Discord and Spotify integrations are used on the personal ESP32-C6 device.

1. Information used by Desk Buddy

For Discord, Desk Buddy is designed to use the authorized user's presence/status, current game or activity, current voice-channel state, and mute/deafen state. For Spotify, Desk Buddy uses playback information such as the current track, artist, album, playback position, duration, and artwork needed to render the OLED interface.

2. What Desk Buddy does not intentionally collect

Desk Buddy does not intentionally collect or store Discord message content, direct-message content, reactions, or a server-wide archive of member activity. It does not provide a Discord messaging or moderation interface.

3. Where the data goes

The firmware communicates with the relevant third-party APIs directly from the ESP32-C6. The project does not operate a developer-owned cloud database for Discord or Spotify activity. Service state is held transiently in the device's runtime memory for display and firmware operation.

4. Credentials

API credentials and integration configuration are intended to be supplied locally to the firmware build. Desk Buddy does not intentionally upload those credentials to a developer-operated cloud service.

5. Third-party services

Discord and Spotify process information according to their own policies. Desk Buddy only controls its own firmware behavior; it does not control how a third-party service handles information on its platform.

6. Data retention

Desk Buddy is designed without a persistent developer-side database for user activity. Temporary state required for the current device session may exist in device memory and local filesystem storage used by the firmware, such as cached artwork.

7. Security

Reasonable care is taken to avoid exposing credentials in the public source repository. Users are responsible for keeping their own API credentials, device configuration, and hardware secure.

8. Children's privacy

Desk Buddy is a technical personal project and is not directed at children. Users should comply with the age and account requirements of any third-party service they connect.

9. Changes to this policy

This policy may be updated when Desk Buddy's data handling changes. The effective date above will be updated for material revisions.

10. Contact

Questions about Desk Buddy's privacy practices can be raised through the project's public GitHub repository or the contact methods listed on Rithwik's portfolio.
